# KjobsUltimate V3.16 — HUD + diagnostics

## Objectif

V3.16 est la phase finale de finition performance du HUD.

Elle apporte :

- cache complet des references NMS ;
- scheduler HUD active-only ;
- ActionBar throttlee ;
- correctif visuel du faux Wither ;
- `/kjobs perf` et `/kjobs perf reset`.

## Particules du Wither

Sur le client 1.8, rendre un Wither invisible ne coupe pas ses particules.

Une bossbar avec une faible progression donne aussi une faible vie au faux
Wither. Sous 50 % de vie, le client utilise son etat armored et peut afficher
des effets supplementaires.

V3.16 applique donc deux protections :

1. le timer d'invulnerabilite NMS du faux Wither est force a zero ;
2. le Wither du HUD normal est place sous le joueur quand
   `hide_wither_particles=true`.

Configuration :

```yaml
bossbar:
  hide_wither_particles: true
  particle_safe_offset_y: -30.0
```

Le test staff reste volontairement libre :

```text
/kjobs testhud wither front invisible
```

Il peut donc encore montrer les particules. C'est normal : il sert justement
a tester le comportement du client avec l'entite devant lui.

## Cache NMS

Avant V3.16, plusieurs chemins HUD faisaient regulierement :

```text
Class.forName
getMethod
getField
getConstructor
```

V3.16 introduit `HudNmsAdapter`.

Ces references sont resolues une seule fois lors de la creation du HudManager
puis reutilisees pour :

- ActionBar ;
- Title ;
- BossBar spawn/update/destroy ;
- Packet statistic du toast.

## Scheduler active-only

Le scheduler ne parcourt plus tous les joueurs ayant deja cree un etat HUD.

Il ne garde actifs que les joueurs avec au moins un de ces besoins :

- fenetre XP en accumulation ;
- ActionBar encore affichee ;
- BossBar XP visible ;
- BossBar de test.

Lorsqu'il ne reste plus rien a afficher, l'UUID sort de la collection active.

## ActionBar

L'ActionBar est envoyee :

- au flush de la fenetre d'accumulation ;
- au maximum selon `performance.actionbar_refresh_interval_ticks` tant qu'elle
  doit rester visible ;
- une seule fois vide a l'expiration.

## /kjobs perf

```text
/kjobs perf
/kjobs perf reset
```

Le rapport couvre :

- actions metier ;
- units comptabilisees ;
- cooldowns blocs ;
- coalescing Kgui ;
- QuestWriteBuffer ;
- HUD active/tracked ;
- temps scheduler HUD ;
- packets HUD ;
- cache/reflection NMS ;
- placements particle-safe.

`perf reset` pose simplement une nouvelle baseline : les compteurs internes ne
sont pas modifies.
