
## 2. Blé

Avec Farmer actif :

- casser un blé mûr
- vérifier XP Farmer
- vérifier quête `HARVEST/CROPS`

Un ancien `farmer.yml` utilisant `WHEAT` doit encore donner l'XP.

## 3. Canne à sucre

Tour de 3 :

```text
haut
milieu <- casser ici
bas
```

Attendu :

- XP = action.xp x2
- quête HARVEST +2
- le bloc du bas reste intact
- aucun second gain si un plugin émet un BlockBreakEvent sur le haut

Puis casser seulement le haut :

- XP x1
- quête +1

## 5. Artisan vanilla normal

Recette résultat x1 :

- `count_mode: CRAFTS`
- XP x1
- quête +1

Recette résultat x4 :

- `CRAFTS` -> XP/quête x1
- `RESULT_ITEMS` -> XP/quête x4

## 6. Artisan shift-click

Préparer plusieurs crafts possibles.

Attendu :

- `CRAFTS` -> nombre de recettes exécutables
- `RESULT_ITEMS` -> recettes x taille résultat
- XP / money / quête ont la même unité

## 7. Kcraft fallback

Sans clé `KCRAFT:<id>` :

- utilise l'action du Material résultat.

## 8. Kcraft exact

Ajouter :

```yaml
"KCRAFT:pioche_azurite":
  xp: 120
  money: 10
  silktouch: false
  count_mode: CRAFTS
  allow_forced: false
```

Attendu :

- l'action exacte gagne sur le fallback Material.

## 9. Craft forcé

Avec `allow_forced: false` :

- 0 XP
- 0 money
- 0 progression quête

Avec `allow_forced: true` :

- accounting normal.

## 10. Quête Kcraft

Attendu en V3.13 :

- un seul signal `CRAFT`
- target = Material du résultat
- amount = la même valeur `units` que l'XP/money
- aucun double avancement de chaîne via un second signal KCRAFT
