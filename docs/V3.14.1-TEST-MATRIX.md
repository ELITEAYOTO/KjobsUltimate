```powershell
mvn clean package
git diff --check
git status --short
```

Attendu :

```text
BUILD SUCCESS
Tests run: 31, Failures: 0, Errors: 0
```

Le nombre exact peut être supérieur si d'autres tests ont été ajoutés.

## Démarrage avec defaults propres

Pour un serveur de DEV sans donnée à préserver :

1. arrêter le serveur ;
2. supprimer `plugins/KjobsUltimate/` ou remplacer ses YAML avec
   `server-defaults/KjobsUltimate/` ;
3. remettre le nouveau jar ;
4. démarrer.

Attendu dans les logs :

```text
6/6 jobs chargés
Quêtes chargées
Validation configs/jobs OK.
Storage SQLITE initialisé
```

Aucun warning de courbe XP.
