# KjobsUltimate V3.14.1 — Clean Baseline Hotfix

Base :
- branche `refactor/v3-foundation`
- commit V3.14 : `7935718876f5659f52506edf43b69a21abda7535`

## 1. Correctif SQLite

L'erreur :

```text
[SQLITE_ERROR] near "ON": syntax error
```

venait du chemin SQLite de `QuestProgressStore`.

V3.14.1 n'utilise plus :

```sql
ON CONFLICT(uuid, quest_id) DO UPDATE
```

sur SQLite.

Le merge monotone utilise :

1. `INSERT OR IGNORE`
2. `UPDATE ... MAX/MIN`

MySQL conserve son `ON DUPLICATE KEY UPDATE`.

## 2. Configs par défaut propres

Remis à jour :

- `config.yml`
- `quests.yml`
- les 6 fichiers `jobs/*.yml`

Le dossier `server-defaults/KjobsUltimate/` contient exactement les fichiers
à copier dans `plugins/KjobsUltimate/` pour repartir avec une configuration
neuve.

## 3. Courbes XP

Chaque job possède désormais les 50 paliers explicites.

Conséquences :

- aucune chute de courbe au niveau 6/11 ;
- aucun fallback partiel ;
- aucun warning "x/50 paliers explicites" sur les defaults.

Les premiers niveaux déjà définis avant V3.14.1 sont conservés exactement.
La suite est monotone.

## 4. Pas de migration legacy

Le projet étant encore uniquement en développement :

- le blé utilise `CROPS` ;
- la chaîne farmer default est `farmer_crops` ;
- aucune ancienne clé de config n'est documentée ;
- aucune migration de données n'est fournie.
