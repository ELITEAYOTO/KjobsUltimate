
## 3. Coalescing réel

Temporairement :

```yaml
debug_quest: true
```

Faire progresser rapidement une même quête (STONE, CROPS, etc.).

Après environ 2 secondes, chercher :

```text
[QuestWriteBuffer] batch=..., pending=..., coalesced=...%, time=...ms
```

Sur une action répétée rapidement, `coalesced` doit devenir nettement > 0%.

## 4. Persistance après restart

1. faire progresser une quête sans la terminer ;
2. attendre au moins 2-3 secondes ;
3. restart propre ;
4. vérifier la progression.

Attendu : progression conservée.

## 5. Completion prioritaire

Terminer une quête.

Attendu :

- message de completion normal ;
- pas d'erreur SQL ;
- progression complète conservée après restart.

## 6. Claim

Claim la récompense d'une quête terminée.

Attendu :

- une seule distribution ;
- `claimed=true` persistant ;
- aucune réouverture après restart.

## 7. Reset administratif

Faire progresser une quête puis :

```text
/kjobs questreset <joueur> <questId>
```

Attendu :

- progression RAM = 0 ;
- progression DB = 0 après restart ;
- une ancienne écriture buffered ne remet jamais l'ancien progrès.

## 8. Quit rapide

Faire plusieurs progressions puis se déconnecter immédiatement.

Attendu : état conservé au retour.

## 9. Shutdown avec pending

Faire progresser une quête et arrêter proprement le serveur avant les 2 secondes.

Attendu dans les logs :

```text
[QuestWriteBuffer] Shutdown - saved=..., failed=0, pendingIgnored=0
```

Puis progression conservée au redémarrage.

## 10. Charge logique

Faire beaucoup d'actions sur une seule quête pendant une fenêtre.

Attendu : le nombre de snapshots SQL suit le nombre de paires `(joueur, quête)`
modifiées, pas le nombre d'actions.
