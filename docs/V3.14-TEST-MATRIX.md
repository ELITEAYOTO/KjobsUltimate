# KjobsUltimate V3.14 — Test Matrix

## 1. Build

```powershell
mvn clean package
git diff --check
git status --short
```

Attendu : `BUILD SUCCESS` et aucune erreur `git diff --check`.

## 2. Reload

```text
/kjobs reload
```

Attendu :

- aucune erreur ;
- jobs/quêtes toujours chargés ;
- HUD toujours fonctionnel ;
- Kgui toujours connecté.

## 3. Mineur

Tester :

- STONE générique ;
- au moins une action `MATERIAL:data` si configurée ;
- REDSTONE_ORE ;
- GLOWING_REDSTONE_ORE ;
- Silk Touch sur une action bloquée ;
- Creative/Spectator et permission officielle de bypass.

Attendu : gameplay identique à V3.13.

## 4. Cooldown bloc

Avec `block_position_cooldown > 0` :

1. casser un bloc récompensé ;
2. replacer/casser immédiatement la même coordonnée ;
3. vérifier que le deuxième gain est bloqué ;
4. quitter/revenir : le cache runtime doit être reparti vide.

## 5. Farmer

Tester :

- blé mûr avec action `CROPS` ;
- carotte/patate ;
- canne à sucre milieu d'une colonne ;
- cactus milieu d'une colonne.

Attendu : même accounting V3.13, sans action legacy `WHEAT`.

## 6. Hunter + KStacker

- mob normal => units=1 ;
- stack/ghost KStacker => units jusqu'au cap 3 ;
- XP, money et quête doivent scaler avec la même quantité.

## 7. Pilleur

- explosion TNT ;
- craft TNT normal ;
- shift-click de plusieurs TNT ;
- dynamite reconnue par `pilleur.dynamite_item`.

Attendu : XP / money / quête identiques en quantité.

## 8. Prétorien

- kill ennemi ;
- relation MEMBER/ALLY/TRUCE bloquée selon config ;
- victim cooldown ;
- last-hit attribution ;
- quit/rejoin.

La seule permission bypass acceptée doit être :

```text
kjobsultimate.bypass.gamemodecheck
```

## 9. Permission XP cache

1. donner `kjobsultimate.xp.vip` ;
2. gagner de l'XP ;
3. retirer la permission ;
4. attendre au maximum le TTL configuré (100 ticks par défaut) ;
5. regagner de l'XP.

Attendu : le multiplicateur se met à jour après expiration du cache.

## 10. Event multiplier

```text
/kjobs event 2
```

Attendre au maximum `event_multiplier_refresh_ticks` (20 ticks par défaut),
puis vérifier que l'XP est doublée.

Remettre ensuite :

```text
/kjobs event 1
```

## 11. Daily cap

Activer temporairement un petit cap global et/ou job :

- vérifier qu'il est respecté ;
- vérifier qu'aucune erreur n'apparaît pendant une récolte rapide.

## 12. Kgui coalescing — test fonctionnel

Avec un menu Kjobs ouvert :

- gagner de l'XP qui fait aussi progresser une quête ;
- vérifier que le GUI se rafraîchit normalement ;
- vérifier qu'il n'y a aucune frame/menu bloqué ou valeur ancienne.

Le flush est différé d'un tick par défaut.

## 13. Smoke test charge

Pendant 1 à 3 minutes :

- miner rapidement ;
- récolter canne/cactus ;
- tuer des mobs ;
- ouvrir/fermer les GUI ;
- changer de job/favori.

Vérifier :

- aucune exception ;
- aucun retard visible du HUD/GUI ;
- mémoire stable ;
- aucune croissance anormale après quit/rejoin.

## 14. Anciennes configurations volontairement supprimées

Ne doivent plus être utilisées :

```text
anti_abuse.pvp_target_cooldown
WHEAT comme action de bloc Farmer
pilleur.dynamite_nbt_example
```

`plugin.yml` ne déclare plus les permissions historiques `kjob.*`.
