## Testhud volontaire

```text
/kjobs testhud wither front invisible
```

Ce test IGNORE le placement particle-safe.

Il est donc normal d'y revoir les particules du Wither.

Comparaison possible :

```text
/kjobs testhud dragon front invisible
```
